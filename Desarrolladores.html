Sobre el Proyecto

Este sistema fue desarrollado como parte de un proyecto académico para demostrar habilidades en diseño y desarrollo web con PHP y MySQL.

Incluye funcionalidades de inventario, despacho, control de productos y gestión de usuarios con autenticación segura.

El sistema fue diseñado para ser moderno, fácil de usar y adaptable a distintos escenarios empresariales.
